# 📖 Introduction

Welcome to **Akcent Docs**!

Akcent Docs is a community-maintained documentation project created to help **Restaurant Tycoon 3 Wiki editors** learn, improve, and contribute with confidence.

Whether you're making your very first edit or you're an experienced contributor looking for a quick reference, this documentation brings together guides, resources, examples, and best practices in one place.

---

## Why Akcent Docs?

When I first started editing the **Restaurant Tycoon 3 Wiki**, I had very little experience with wiki editing or Source (Wikitext).

Like many new editors, I learned through:

- Trial and error
- Advice from experienced community members
- Official documentation
- Community guides
- Lots of experimentation

As I continued editing, I collected useful websites, examples, templates, and notes that helped me improve.

Eventually, that collection became large enough that I decided to organise everything into a single documentation project that other editors could benefit from.

That's how **Akcent Docs** was created.

---

## My Goal

The goal of Akcent Docs is simple:

- 📚 Make learning wiki editing easier.
- ✍️ Help editors write better articles.
- 💡 Share useful tips and best practices.
- 🤝 Bring community knowledge together.
- 🚀 Help new contributors become confident editors.

Rather than searching through dozens of different websites, this documentation aims to provide one organised place to find the information you need.

---

## Who is this documentation for?

Akcent Docs is designed for everyone in the Restaurant Tycoon 3 Wiki community, including:

- 🆕 New editors learning Source (Wikitext)
- ✏️ Existing contributors
- 📑 Template editors
- 📖 Documentation writers
- 🔍 Anyone looking for quick formatting references

Whether you're editing one page or hundreds, there's something here that can help.
