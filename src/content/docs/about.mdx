# ❤️ About Akcent Docs

Akcent Docs is a **community-maintained documentation project** created to help editors of the **Restaurant Tycoon 3 Wiki** by an editor of the **Restaurant Tycoon 3 Wiki**.

The project aims to bring together guides, references, examples, and useful resources into one organised place, making wiki editing easier for both new and experienced contributors.

---

# 🎯 My Mission

The goal of Akcent Docs is simple:

- 📚 Make learning Source (Wikitext) easier.
- ✍️ Help editors create high-quality articles.
- 💡 Share useful editing techniques.
- 🤝 Encourage community collaboration.
- 🚀 Provide a reliable reference for RT3 Wiki editors.

Rather than searching through dozens of different websites, Akcent Docs collects the most useful information into a single documentation site.

---

# 🌱 Why This Project Exists

Like many editors, I started with very little knowledge of wiki editing.

Most of what I learned came from:

- Trial and error
- Community advice
- Official documentation
- Reading other editors' work
- Experimenting with templates and formatting

Over time I built a collection of notes, references, and examples that became increasingly useful.

Akcent Docs was created to organise that knowledge so other editors could learn from it too.

---

# 🚀 Open Source

Akcent Docs is an open project.

That means anyone can:

- Suggest improvements
- Report issues
- Recommend useful resources
- Contribute new documentation
- Help improve existing guides

Community feedback helps keep the documentation accurate and up to date. (Just dm when you do make a change)

---

# 🛣 Roadmap

Akcent Docs will continue to grow over time.

Future improvements include:

- More Wikitext examples
- Advanced template guides
- Better formatting references
- Additional troubleshooting guides
- More community resources
- Expanded Reference Library

As the RT3 Wiki evolves, Akcent Docs will evolve alongside it.
