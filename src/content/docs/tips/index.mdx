# 💡 Tips & Tricks

Editing a wiki becomes much easier once you develop good habits. This page collects practical tips and best practices to help you edit more efficiently and avoid common mistakes.

---

## ✨ General Editing Tips

- Start with small edits before tackling larger projects.
- Read the entire page before making changes.
- Follow the formatting already used on the page whenever possible.
- Keep articles consistent with the rest of the wiki.
- If you're unsure about a change, ask another editor before publishing it.

---

## 📝 Use Edit Summaries

Every time you save an edit, write a short edit summary.

Good examples:

- Fixed spelling mistakes
- Updated Build Mode section
- Added missing images
- Corrected formatting

A clear edit summary helps other editors understand what changed.

---

## 👀 Always Preview Your Changes

Before saving:

- Click **Show Preview**
- Check headings
- Check links
- Check spelling
- Check tables
- Check templates
- Make sure images appear correctly

Previewing your work prevents accidental mistakes from being published.

---

## 📚 Keep Formatting Consistent

Consistency makes the wiki easier to read.

Try to keep:

- Heading sizes consistent
- Lists formatted the same way
- Images aligned similarly
- Tables using the same style
- Template usage consistent across similar pages

If you're unsure, compare your page with another well-written article.

---

## 🔗 Double-Check Links

Before saving, verify that:

- Internal links point to the correct page.
- External links still work.
- There are no unnecessary duplicate links.
- Red links are intentional.

Broken links make navigation more difficult for readers.

---

## 📷 Working with Images

When adding images:

- Use clear file names.
- Upload high-quality images.
- Avoid blurry screenshots.
- Keep image sizes reasonable.
- Add captions where helpful.

Images should support the article—not distract from it.

---

## 📑 Organise Information Clearly

Instead of writing large blocks of text:

- Use headings
- Use bullet lists
- Break information into sections
- Add tables where appropriate
- Keep paragraphs short

Well-organised pages are easier to read and maintain.

---

## 🚫 Common Mistakes

Try to avoid:

- Forgetting to preview changes.
- Creating duplicate pages.
- Removing information without explanation.
- Breaking templates.
- Using inconsistent formatting.
- Saving large edits without an edit summary.
- Posting information to early. 

Everyone makes mistakes—learning from them is part of becoming a better editor.

---

## ⭐ Productivity Tips

As you gain experience:

- Bookmark useful reference pages.
- Keep a list of commonly used templates.
- Save useful code snippets.
- Learn keyboard shortcuts.
- Review other editors' work to discover new techniques.

Small improvements to your workflow can save a lot of time over many edits.

---

## 🤝 Work With the Community

The RT3 Wiki is a collaborative project.

Remember to:

- Be respectful of other contributors.
- Accept constructive feedback.
- Discuss major changes when needed.
- Help new editors whenever you can.
- Receive help from older members. 
- Share useful discoveries with the community.

Working together leads to a better wiki for everyone.
