## Welcome

Akcent Docs is a community-maintained documentation website created to help **Restaurant Tycoon 3 Wiki editors** learn Source (Wikitext), discover editing techniques, and contribute with confidence.

Whether you're creating your **first article** or improving an existing page, you'll find practical guides, examples, and reference material to help you along the way.
