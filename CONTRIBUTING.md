# 🤝 Contributing to Akcent Docs

First of all, thank you for considering contributing to **Akcent Docs**!

This project exists to help the Restaurant Tycoon 3 Wiki community by providing clear, accurate, and beginner-friendly documentation. Every contribution—whether it's fixing a typo or writing a new guide—is appreciated.

---

# 📖 Before You Start

Please take a few minutes to:

- Read the documentation.
- Search existing issues before creating a new one.
- Keep discussions respectful and constructive.
- Follow the project's writing style and formatting.

---

# 🐞 Reporting Issues

If you've found a mistake or bug, please include:

- A clear description of the issue.
- The page where it occurs.
- Steps to reproduce the problem (if applicable).
- Screenshots, if they help explain the issue.

---

# 💡 Suggesting Improvements

Suggestions are always welcome!

Examples include:

- New documentation pages
- Better explanations
- Additional examples
- New reference material
- Improved formatting
- Navigation improvements

Please explain why your suggestion would improve Akcent Docs.

---

# ✍️ Writing Guidelines

When writing documentation:

- Use clear and simple language.
- Explain technical terms.
- Keep paragraphs short.
- Use headings to organize content.
- Include examples whenever possible.
- Test all links before submitting changes.

---

# 📚 Documentation Standards

Every page should include:

1. A clear title.
2. A short introduction.
3. Well-organized sections.
4. Examples where appropriate.
5. Links to related pages.

Use Starlight callouts to highlight important information:

```md
:::
Helpful advice.
:::

:::
Additional information.
:::

:::
Potential issues to be aware of.
:::
