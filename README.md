# 📚 Akcent Docs

> Community-maintained documentation for Restaurant Tycoon 3 Wiki editors.

---

## 🌟 About

**Akcent Docs** is a community-driven documentation website designed to help editors of the **Restaurant Tycoon 3 Wiki**.

Whether you're making your first edit or maintaining large sections of the wiki, Akcent Docs provides tutorials, references, examples, and resources to make editing easier and more approachable.

The project is built with **Astro** and **Starlight**, with a focus on clear writing, practical examples, and long-term maintainability.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/AkcentG/akcent-docs.git
```

Navigate to the project:

```bash
cd akcent-docs
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:4321
```
